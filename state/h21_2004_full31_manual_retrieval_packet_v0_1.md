## 4. 반드시 촬영/복사할 페이지

최소한 다음을 한 번에 확보한다.

1. **기사 첫 페이지** — 제목, 발행일/권호, 페이지 확인용
2. **31명 전체 순위표가 있는 페이지**
3. 표가 두 페이지에 걸치면 양쪽 페이지 전체
4. **조사방법론 박스/주석이 있는 페이지**
5. 가능하면 기사 마지막 페이지까지 연속 촬영

사진은 표만 잘라 찍지 말고 **페이지 가장자리와 페이지 번호가 보이게** 촬영한다.

## 5. 회수해야 하는 데이터

### 필수

- rank 1–31 이름 전부
- 각 rank의 composite score가 있으면 전부
- 특히 현재 missing인 **11–21, 23–31**의 20명
- 8–10위와 22위의 미노출 score
- 31명 후보 pool이 ranking table과 별개라면 그 후보 목록도 전부

### 방법론

- 질문 문구
- 호감도 문항의 응답척도
- 국정수행능력 문항의 응답척도
- composite 계산 방식
- 조사기관
- 조사일
- 표본수
- 표집/전화면접 방법
- 오차범위

### provenance

각 전사 행에:

- issue no.
- publication date
- page no.
- image/PDF filename
- table/figure title

을 붙인다.
